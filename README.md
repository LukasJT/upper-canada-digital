# Upper Canada Digital

Marketing website for **Upper Canada Digital** — a Canadian web studio building fast, affordable, easy-to-manage websites for remote and northern communities across Canada.

## What's here

A lightweight, dependency-free static site — perfect for GitHub Pages.

```
HudsonsBayDigital/
├── index.html         # Single-page site (hero, services, mission, process, about, contact)
├── styles.css         # All styling (dark "northern field guide" theme, responsive, accessible)
├── script.js          # Header-on-scroll, mobile nav, scroll reveal (no frameworks)
├── assets/
│   ├── logo.png        # Header emblem (cropped from the brand logo)
│   ├── logo-full.png   # Full logo lockup (emblem + wordmark + tagline)
│   ├── favicon.png     # Site icon (emblem)
│   ├── hero-aurora.svg # Custom aurora-over-treeline hero illustration
│   ├── treeline.svg    # Spruce silhouette used above the footer
│   └── topo.svg        # Subtle topographic-contour background texture
└── README.md
```

No build step, no npm, no frameworks — just open `index.html`.

**Design:** a bright, cartographic look — cream "map paper", a royal-blue brand taken
from the logo, heritage point-blanket stripe accents, and one dark aurora hero as a
focal accent. Type is **Fraunces** (editorial serif display), **Space Grotesk**
(body), and **Space Mono** (technical labels), loaded from Google Fonts. To keep the
site fully self-contained for the lowest-bandwidth visitors, you can later self-host
those three fonts and drop the `<link>` tags in `index.html`.

**Logo:** the header uses `assets/logo.png` — the emblem cropped from the brand logo.
The complete lockup (with wordmark and tagline) is kept as `assets/logo-full.png`.
To change either, just replace the file with a same-named image.

The SVG scenery (hero aurora, treeline, topo texture) was generated by scripts kept
out of the repo; the finished files in `assets/` are all the site needs.

## Run locally

Open `index.html` directly in a browser, or serve it:

```bash
python -m http.server 8000
# then visit http://localhost:8000
```

## Deploy to GitHub Pages

1. Push this folder to the `main` branch of `LukasJT/HudsonsBayDigital`.
2. In the repo, go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Choose branch **`main`** and folder **`/ (root)`**, then **Save**.
5. Your site goes live at `https://lukasjt.github.io/HudsonsBayDigital/` in a minute or two.

To use a custom domain (e.g. `hudsonsbaydigital.ca`), add it under Settings → Pages → Custom domain and point your DNS at GitHub Pages.

## Things to customize

- **Contact email** — replace `hello@hudsonsbaydigital.ca` in `index.html` with your real address.
- **Contact form** — the form posts to a placeholder Formspree endpoint (`https://formspree.io/f/your-form-id`). Create a free form at [formspree.io](https://formspree.io) and swap in your form ID, or point the form wherever you like.
- **Copy** — the section text is a solid starting point; edit it to match your voice and real services.
